After each upload

  1. Open the saved Individual records — Review and download table from your bookmark or the Charts list.
  2. Click Update chart to read the latest uploaded tables.
  3. Open ⋯ → Data Export Options → Export All Data → Export to .CSV.
  4. Open the CSV in Excel or another spreadsheet application.

Use the chart's data export. The Export action in the Datasets list downloads YAML definitions for moving a dataset between Superset instances. It does not download the records.

What the file contains

  • Individual records from Current and Historical, identified by a source column.
  • record_ID from both sources and redcap_repeat_instance from Current. Historical repeat values are blank.
  • Hospital, reporting month, selected review fields, and an explanation for records excluded from reporting.

The table opens separately, so the main dashboard's hospital and date selections do not narrow it. It contains 20 review columns. Monthly totals and rates are a different output: UTI Aggregate ALL DATA.

Availability: this supporting table is available on our demo. For the client instance, follow the one-time record-review setup, with downloadable SQL. This is separate from the main dashboard update; it uses the existing connection and leaves the reporting calculations in place.

Verification and export size

The recording's CSV was checked across all 3,453 demo records and all 20 columns, including repeat identifiers and duplicate rows. The saved query has a 100,000-row limit. Export All Data includes the query result rather than only the visible page, but it remains subject to that limit.
