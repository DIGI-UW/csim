Download the aggregate results

Use the saved Aggregate ALL DATA — Download table after uploading Current. It contains the rows already calculated by the aggregate dataset, without another layer of aggregation.

Open the download table → · Open the dashboard · Login details

Upload → refresh → download

  1. Upload Current through the existing upload process.
  2. Follow Aggregate ALL DATA — Download near the top of the dashboard.
  3. Click Update chart to refresh the saved table.
  4. Open ⋯ → Data Export Options → Export All Data → Export to .CSV.

The table opens separately. Date, hospital and location choices on the dashboard do not narrow its export. Export All Data includes the complete result, rather than only the displayed page.

What is in the file?

All 25 dataset columns and all 9,801 rows from the current demonstration database. Every CSV value has been compared with the full aggregate query. These are calculated aggregate rows, including hospital, state and cohort results and the dataset’s calendar rows.

Raw records is Superset’s name for displaying the dataset output without aggregating it again. This saved chart does not create another database table and does not export the original individual records.

Refresh after an upload

A controlled CSV upload to the known-record fixture added a new reporting month. Update chart changed the aggregate result from 48 to 56 rows, and every value in the new CSV matched the full query. The fixture was restored after the check.

The saved row limit is 100,000. When the source grows substantially, verify that the complete result remains below that limit.
