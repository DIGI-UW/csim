# Inclusive month controls on the snapshot

The second snapshot dashboard keeps the full 20-chart Individual Data report and its six dataset definitions. It offers **From month**, **Through month (inclusive)** and **Group by: Month / Quarter / Year**. The original snapshot dashboard remains available.

The month controls produce Superset's standard date range: February through March becomes February 1 up to, but excluding, April 1. Dataset SQL filters observations before grouping. Quarter therefore labels that result Q1 but includes no January observations. A message beside the controls names the partial quarter or year. These are reporting months from the supplied database, not arbitrary daily cutoffs.

Incomplete or reversed ranges disable Apply. Clearing and reselecting must recover on the same page. The new dashboard opens with an explicit November 2025–April 2026 window; the original retains Cohort, Last year and Month defaults.

## Reproduce

Use the pinned snapshot configuration created by `bash csim.sh preview config`. Build and start its month-control image without restoring the database:

```sh
export CSIM_DOCKERFILE=Dockerfile.month-controls
export CSIM_BUILD_TAG=e22ce197-csim-months-1
bash csim.sh preview update
bash csim.sh preview simple
bash csim.sh preview viewer
cd e2e
CSIM_PROFILE=preview npm exec playwright test -- -c month-controls.config.mjs
CSIM_PROFILE=preview CSIM_DATA_PROFILE=edge-cases CSIM_DASHBOARD_SLUG=csim-month-examples npm exec playwright test -- -c month-controls.config.mjs
```

The existing example database must already be initialized with `bash csim.sh preview examples-init`; later changes use `examples-update` and never reseed it. Native packages are generated by `ruby scripts/prepare_dashboard.rb`. Dashboard and chart UUIDs differ from the original; dataset UUIDs and SQL remain shared.

## Acceptance

- All 20 charts load, with eleven date axes and hover labels following the grouping.
- Inclusive endpoints, year boundaries and leap-year February are represented correctly.
- February–March grouped by Quarter excludes January and identifies the partial quarter.
- Grouping changes preserve both month fields; both selection orders give equivalent results.
- Invalid ranges cannot be applied; clear and reselect works without a reload.
- Missing months, valid zero and empty cohorts retain their established meaning.
- The original dashboard and independent hourly menu still work on the same snapshot.
